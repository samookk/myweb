# WindPy 一键获取伦敦金现（XAUUSD）走势

> 适合**零基础**：按步骤做就能导出 Excel。

## 你会得到什么

运行成功后，会在同目录生成：

- `XAUUSD.xlsx`（推荐用 Excel 打开）
- `XAUUSD.csv`

里面包含：

- `close`：收盘价
- `ret`：日收益率（可选计算，第一行会是空）

## 前提条件（必须）

1. **你的电脑能正常打开 Wind 终端**
2. 你的 Wind 账号有 **API 权限**（能用 WindPy）
3. 电脑已安装 Python（推荐 Windows）

## 第一步：下载这套文件到电脑

你需要把 `wind/` 文件夹里的文件下载到电脑任意目录（例如桌面）。

最少需要这两个文件：

- `xauusd_windpy.py`
- `run_xauusd.bat`

## 第二步：双击运行

直接双击：`run_xauusd.bat`

它会自动尝试运行脚本并导出文件。

## 常见问题

### 1）双击后闪一下就没了 / 没看到结果文件

请用以下方式打开窗口运行（这样能看到报错）：

1. 在 `wind/` 文件夹空白处按住 **Shift** 然后右键
2. 选择“在此处打开 PowerShell 窗口”
3. 输入并回车：

```powershell
.\run_xauusd.bat
```

把窗口里显示的报错信息整段复制给我，我帮你改。

### 2）提示找不到 python

优先尝试：

- 直接双击 `run_xauusd.bat`（它会先试 `py` 再试 `python`）

如果还不行，你需要安装 Python：

- 打开微软商店（Microsoft Store）搜索 **Python 3**
- 或者去 python 官网下载安装（不建议你手动配环境变量时先问我）

### 3）提示 WindPy / Wind 未安装

说明你的电脑没有正确安装 Wind 或 WindPy 组件。
通常只要 Wind 终端能正常运行，并且你有 API 权限，WindPy 才能用。

### 4）提示 XAUUSD 没权限 / 返回空

不同账号或数据源，代码可能需要改成你账号可用的形式。
你把报错贴给我，我会根据返回码帮你改成可用代码（例如其他写法或改用可查询的品种代码）。
