配置步骤（3–5 分钟）

你的网站是 GitHub Pages（静态网页）。要做到“手机上传记录 + 数据实时更新”，需要一个云端数据库。 这里用 Firebase（免费额度够个人打卡用）。

1）创建 Firebase 项目

  1. 打开 Firebase 控制台：console.firebase.google.com
  2. 点“添加项目” → 一路下一步即可
  3. 进入项目后，点左侧“项目概览”旁边的小齿轮 → “项目设置”

2）创建 Web 应用并复制配置

  1. 在“你的应用”里点 Web 图标（</>）创建 Web 应用
  2. 创建完成后会看到一段 firebaseConfig
  3. 把它复制到仓库的 tracker-config.js 里（替换 REPLACE_ME）

注意：文件名是 tracker-config.js（上面那行打错了不要紧，按这个为准）。

3）开启 Authentication（邮箱密码登录）

  1. Firebase 左侧：Authentication → “开始使用”
  2. Sign-in method → 启用 Email/Password
  3. Users → 添加用户（用你的邮箱，比如 gc556@cornell.edu）并设置密码

4）创建 Firestore Database

  1. Firestore Database → “创建数据库”
  2. 选择 Production mode（生产模式）
  3. 地区随意（就近）

5）开启 Storage（用于上传截图/照片）

  1. Storage → “开始使用”
  2. 选择 Production mode

6）安全规则（非常重要）

否则别人也可能往你的数据库里写入垃圾数据。

Firestore Rules（复制粘贴，然后把邮箱改成你的）：

rules_version = '2';
service cloud.firestore {
  match /databases/{database}/documents {
    match /users/{userId}/{document=**} {
      allow read, write: if request.auth != null
        && request.auth.token.email == "gc556@cornell.edu"
        && request.auth.uid == userId;
    }
  }
}

Storage Rules（同样改邮箱）：

rules_version = '2';
service firebase.storage {
  match /b/{bucket}/o {
    match /proofs/{userId}/{allPaths=**} {
      allow read, write: if request.auth != null
        && request.auth.token.email == "gc556@cornell.edu"
        && request.auth.uid == userId;
    }
  }
}

完成后怎么用

  1. 打开 tracker.html
  2. 用你创建的邮箱+密码登录
  3. 每天填体重、选跑步/篮球、上传截图 → 提交
  4. 表格会实时更新（换手机登录也能看到）
